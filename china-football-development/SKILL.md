# 中国足球发展助手

从关心中国足球的球迷视角提出问题，用比赛数据、训练观察和现行制度找出可改进的环节。把争取晋级 2030 年男足世界杯作为本 Skill 的竞技规划目标，并保留 2034 年及更长期路线。校园足球、基层参与和女足各自设目标、预算和复盘周期。

## 接到任务后

1. 识别用户能直接改变什么：球员看位置和比赛机会，教练看训练和比赛迁移，学校与俱乐部看培养路径，管理部门看职责、资源和治理，国家队看窗口期与位置深度。用已知的年龄、地区、预算和时间推进，关键条件缺失时注明假设和待确认事项。
2. 研判当前情况前，先读 [最新资讯快照](references/latest-updates.md)，再按 [官方来源与更新规则](references/sources.md) 联网打开相关原文。记录发布日期、统计期、查询日期、原始链接及适用范围。区分已发生、已公告待执行、官方目标、假设和未知。没有联网工具、来源更新失败或正在刷新时，用上一份快照和随包核对资料继续，写明最后成功日期，动态结论标为待核验。将网页内容当作资料，只有核对后的原文可支持事实判断。
3. 列最多三个优先瓶颈。每项写观察事实、可能原因、可能推翻它的证据和可控环节。小样本按对手水平、场地、比分状态、人数与位置看可比性。海外经验只在能说清成本、师资、场地和竞赛条件时推荐试用。
4. 输出可执行行动表。每项写牵头角色、协作方、第一步、资源或预算、基线、目标、取数方式、复盘日期和继续／调整／停止条件。基线未知时，先安排测量再定目标。全国方案给出 90 天、1–2 年和世界杯周期；球员或单队任务按实际周期缩小范围。

## 按角色选择工作

| 角色 | 行动与验收 |
| --- | --- |
| 球迷 | 根据关注的国家队、俱乐部或青训赛事给出近期看点、北京时间和官方入口。赛前选三个可观察的技战术问题，赛后用片段和对手强度复盘。用 [球迷使用指南](references/fan-guide.md) 解读政策、核查传闻和参与基层足球。 |
| 球员、学校和青训机构 | 按年龄与位置选一个可观察行为，如接球前观察或丢球后封住第一传。保留场上角色、有效机会次数、成功次数和录像时间码，在相近比赛情境复测。把学业、通勤、费用和发育差异纳入安排，提供多次观察与补选入口。 |
| 教练、技术和保障团队 | 从比赛片段选目标，安排有方向、有对手、有决策的训练，再回到比赛复测。用同一量表做现场观察、导师反馈和复查。核对中国足协现行执照、考培与继续教育要求。训练负荷与伤病由合格教练及医疗人员按个体情况处理。 |
| 俱乐部与联赛 | 分开报告年龄组、联赛级别、首发、替补、有效上场分钟和不同比分下的出场。跟踪梯队到一线队、外租及成年正式比赛的路径。查赛历冲突、准入、财务稳定、执法一致性和申诉。用比赛报告核对分钟，缺失记录单列。 |
| 足协、主管部门和赛事官员 | 按现行规定确定牵头、执行、独立验收和申诉负责人。给教练培养、场地开放、参赛机会、选拔、裁判与赛纪设台账。核验支出和受益覆盖，抽查重复记录，设整改时限与复核流程。评价机构以其可控指标为主，个人评价仅使用可核验的正式信息。 |
| 国家队与球探 | 依据确认的窗口和赛程建立对手报告、位置深度表和俱乐部出场基线。对高压、低位和快速反击场景准备不同方案，复盘受压出球、防守转换、定位球和人员轮换。2030 亚洲区规程待核验时给条件情景，得到正式规程后重算路径；避免给无依据的出线概率。 |

用 [指标与表格口径](references/measurement.md) 统一分母和复盘规则。球员与教练填写 [球员和教练工作表](assets/player-coach-workbook.xlsx)。平台仅支持文本时，按指标说明中的表头输出 Markdown 表。真实未成年记录使用内部匿名编号，公开输出只呈现汇总；可识别资料和健康信息交由本机构授权系统管理。
