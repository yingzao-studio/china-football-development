# 指标口径与表格用法

复制工作簿后保留表头，示例行只作演示，不并入统计。同一队固定定义、观察窗口和记录人。用「未观察」说明不可用的场次；确实观察到零次才记 0。先用共同片段对齐定义，再安排第二观察员复核。基线和复测都报告人数、机会次数、比赛级别、位置与比分状态；机会太少时延长观察。

| 指标 | 取数与复盘 |
| --- | --- |
| 接球前观察率 | 选定可判读的接球机会。接球前 2 秒内清晰观察到转头扫视周边记成功。镜头看不清的机会从分母剔除并另记。按位置和是否受压看，保留分子和分母。 |
| 受压处理成功率 | 赛前统一「受压」标准，例如接球时对手处于可立即争抢距离。以受压且可判读的接球为分母；用预先约定的保住球权或完成有效推进记成功。避免混用不同距离标准。 |
| 受压出球到达率 | 以一次从本方后场开始、遭遇高压且画面完整的控球序列为单位；本方受控把球推进至中三区记成功。先固定区域划线和高压判定，明确门球与开放比赛是否分开。 |
| 防守转换暴露率 | 以指定区域且可判读的丢球为分母；例如约定丢球后 8 秒内对方受控入禁区或射门记一次暴露，同一回合只记一次。记录比分和人数。 |
| 训练到比赛迁移 | 同一行为、同位置或同角色，记录训练观察和正式比赛观察。按「成功总次数 ÷ 有效机会总次数」汇总，同时报告每人覆盖；不平均各场百分比。 |
| 有竞争价值的分钟 | 先报告全部正式出场分钟，再按预先定义的比分情境和对手级别切片。不能重建比分状态时只报告总分钟并标注缺口。跟踪首发、连续出场及赛季留存，成年正式比赛与梯队赛事单列。 |
| 通道转化 | 固定入组批次与期限，分母用期初符合条件且可跟踪人数，分子用期限内进入指定下一层且有实际参赛记录的人数。退训、迁出和失访单列，记录变动原因。 |
| 教练现场观察 | 1＝有机会但未体现，2＝部分体现或不稳定，3＝有明确证据且反复体现。没观察到记「未观察」；评分必须附事实或时间码。每次只选一项改进，安排同类场景复查。 |
| 治理整改 | 用同口径报告到期事项数、按期复核通过数、重开数。验收人检查原始凭据，按期结案率以到期且已复核事项为准，同时披露到期未验收事项。 |

仅能用文本的模型可直接复制以下表头。人员编号不采用姓名、身份证号或联系方式。引用未成年视频只留内部片段编号和时间码。

| 表 | 字段 |
| --- | --- |
| 球员跟踪 | 周次／球员编号／组别／位置／训练参加与计划次数／正式比赛分钟／目标行为／有效机会／成功／录像时间码／下一步／复测日 |
| 教练现场观察 | 日期／教练编号／组别／观察项目／评分／事实或时间码／改进动作／复查日期／复查结果 |
| 教练改进计划 | 教练编号／球员目标行为／原基线（成功／机会）／训练任务／比赛复测方法／导师／复测日／结果与决定 |

建议教练现场观察依次覆盖目标清晰度、练习是否保留比赛决策、反馈时机、参与机会和比赛复测。实际观察、示例与政策目标使用独立记录。
